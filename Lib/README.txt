These files power ZoneSnap's modern window. Keep this Lib folder next to ZoneSnap.ahk.

WebView2\WebView2.ahk, ComVar.ahk, Promise.ahk, JSON.ahk
  From thqby's ahk2_lib (https://github.com/thqby/ahk2_lib), MIT licence - see LICENSE-ahk2_lib.txt.
WebView2\64bit\WebView2Loader.dll, WebView2\32bit\WebView2Loader.dll
  Microsoft's WebView2 loader, as shipped in ahk2_lib.

Without this folder (or ui.html), ZoneSnap still works and uses its classic windows.
