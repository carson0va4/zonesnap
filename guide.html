ZoneSnap user guide

ZoneSnap splits an ultrawide monitor into zones and snaps windows into them, for work and play. Workspaces switch whole setups with one hotkey: say Work, Streaming and Gaming. In gaming mode your game sits in the middle at a proper 21:9 or 16:9 size, borderless, with the cursor locked to it and chat, music or a guide in panes on either side, and a game can have its own layout, like 4:3 for a retro title.

Getting started

ZoneSnap lives in the system tray, at the bottom right of your screen (you may need to click the ^ arrow to see it). The first time it runs it looks at your monitor, creates a starting layout and opens its window with a short welcome. On a 3840 × 1080 monitor, for example, you get a 2560-wide game zone in the middle with a 640-wide pane on each side.

Your first five minutes

  1. Snap a window. Hold Alt, press the left mouse button anywhere inside a window and drag it. The zones light up; let go over one and the window fills it exactly.
  2. Adjust the zones if you like. Press Ctrl+Alt+Z and drag the handles between zones on the picture of your monitor.
  3. Tell ZoneSnap about your side apps. Press Ctrl+Alt+G to switch gaming mode on, put Discord, Spotify or anything else in a side zone, click it, and press Ctrl+Alt+A; it's added to gaming mode. Do the same with your game in the middle zone, so ZoneSnap knows it's a game. Press Ctrl+Alt+G again to switch gaming mode off.
  4. Play. Start the game, or press Ctrl+Alt+G. Gaming mode opens your side apps in their zones, makes the game borderless, hides the taskbar, keeps the mouse inside the game and dims the side panes.
  5. Start with Windows. On the General page, turn on Start with Windows so ZoneSnap is always ready.
Reading this inside ZoneSnapClick around ZoneSnap while you read: the guide jumps to the section for the page you're on (untick Follow pages to stop that), and Show in app next to a heading opens the page it describes. F1 opens and closes this panel.

Installing and updating

What you need

  • Windows 10 or 11.
  • The Microsoft Edge WebView2 runtime, which draws the ZoneSnap window. It's built into Windows 11 and up-to-date Windows 10. Without it, zones, gaming mode and your shortcuts still work from the tray icon, but the ZoneSnap window can't open.

Installing

  1. Make a folder of its own for ZoneSnap, for example Documents\ZoneSnap or Program Files\ZoneSnap.
  2. Put ZoneSnap.exe in it and double-click it. (If you have the script version instead, keep ZoneSnap.ahk, ZoneSnap.ico, ui.html, guide.html and the src and Lib folders together and double-click ZoneSnap.ahk. It needs AutoHotkey v2.)
  3. Windows may warn that the app is from an unknown publisher; choose More info → Run anyway.

Your settings are saved in your Windows user folder, in %APPDATA%\ZoneSnap\profiles\<your profile>\ZoneSnap.ini, so everyone who signs in to Windows has their own. Open settings file (General page → Advanced, or the tray menu) opens it. Before 0.37.0 the settings file sat next to ZoneSnap; the first start of 0.37.0 moves it into a profile named after your Windows user name and keeps the old file as ZoneSnap.ini.old.

Updating

ZoneSnap tells you when a new version is out (see Settings). Choose Update now, in the banner on the General page or in the tray menu: ZoneSnap downloads the new version, checks it's the release's own file, replaces itself and restarts. Your settings carry over. If the check fails, the download is deleted and nothing changes.

The script version, or ZoneSnap.exe in a folder it can't save files in (like Program Files), opens the release page instead. To update by hand:

  1. Right-click the tray icon and choose Exit.
  2. Replace ZoneSnap.exe with the new one (or, for the script version, the script files). Your settings are in your user folder, so nothing else needs copying.
  3. Start ZoneSnap again. Everything you set up carries over.

Snapping windows

There are three ways to put a window into a zone:

Do thisWhat happens
Alt + left-dragGrab a window anywhere inside it, not just its title bar, and drag. Zones light up; let go over one to snap. This works on borderless games, which have no title bar to grab.
Shift while draggingDrag a window by its title bar as usual and hold Shift: the zones appear, and the window snaps where you let go.
Ctrl+Alt+1 to 9Sends the active window straight to that zone.
  • Zones are numbered from left to right as they appear on the Zones page; the number shows in the middle of each zone there.
  • If Alt-drag gets in the way of a game, change the drag key to Win + drag or Ctrl+Alt + drag on the General page.
  • Games must run windowed or borderless. Nothing outside a game can move an exclusive-fullscreen window. See Games.
  • Some apps have a minimum window size and won't shrink to fit a narrow zone. See Apps for your side panes for the fix.

Zones and the zone editor

Every workspace has a layout:

  • the Default layout, used for everyday work (whenever no other workspace is on),
  • the Gaming layout, used while gaming mode is on, and
  • a layout for each workspace of your own, which starts as a copy of Default until you save it.

Snapping always uses whichever layout is active. The top line of the tray menu, and the tray icon's tooltip, tell you which one that is.

Editing zones

Press Ctrl+Alt+Z, or choose Edit zones from the tray menu.

  • Pick from the Layout of menu at the top to choose which layout you're editing: Default, Gaming, one of your own workspaces, or a game with its own layout (shown as Gaming · the game). This doesn't change which one is active.
  • Drag the handles between zones to resize them. Zones sharing an edge move together, so a stacked column stays lined up.
  • Click a zone to type exact sizes, split it in two (top/bottom or left/right), make it the game zone, or remove it.
  • Preview on screen shows the zones on your monitor for two seconds.
  • Save applies them straight away. A workspace of your own uses the Default layout until you save one for it here; the first save gives it its own, and the Default layout isn't changed. Revert throws away unsaved changes.

Presets

Presets are worked out from your monitor's resolution, so they suit whatever screen you have:

PresetWhat you get

16:9 gameA 16:9 game (1920 at 1080, 2560 at 1440) with wider side panes.

HalvesTwo equal columns, good for a second monitor.

A preset only changes the picture; nothing happens to your windows until you click Save.

Every workspace is its own layout, so there's nothing else to keep track of. To try something out without losing a layout you like, Duplicate its workspace first, or export your layouts (General → Back up and share).

Workspaces and gaming mode

A workspace is a whole setup you switch on in one go: a layout, the apps to open and snap into it, and a few options. Gaming mode is the built-in Gaming workspace. You can add your own, such as Work or Streaming. One workspace is on at a time. Default is the workspace that's on whenever no other one is: switching a workspace off takes you back to it.

Each workspace has a card on the Workspaces page. Cards start closed, showing the workspace's name, whether it's on, and a one-line summary; click one to open its settings, and click again to close it. ZoneSnap remembers which ones you left open.

Switching a workspace on and off

  • Ctrl+Alt+G switches gaming mode on and off.
  • Your own workspaces can have a hotkey such as Ctrl+Alt+F1.
  • Press Ctrl+Alt+Space for the quick switcher: a list of your workspaces pops up at the mouse, with the active one marked. Press a workspace's number, or use the arrow keys and Enter, or click it. Esc (or clicking elsewhere) closes it. It works mid-game too.
  • Or use Switch on on its card, or the tray menu's Workspaces submenu.

Renaming, copying and ordering workspaces

  • Open a workspace's card and click Rename. Its hotkey, apps and layout go with it. Gaming mode keeps its name.
  • Duplicate starts a new workspace as a copy: the same options, the same app places, and its own copy of the layout (so changing one doesn't change the other). The copy has no hotkey until you give it one.
  • Drag a card by the dots on its left to put your workspaces in the order you want, or click the dots and press the Up and Down arrow keys. The Zones page, the Apps page, the tray menu and the quick switcher follow the same order. Default always comes first.

Switching between workspaces

When you switch straight from one workspace to another, When switching between workspaces decides what happens to the apps the first one opened: leave them open, minimise them, or close them. Games, and apps the new workspace also uses, are never touched.

Going back to Default

When a workspace switches off and you're back on Default, apps you've given a Default zone (see Where apps go on Default) go to that zone, and apps set to Leave where it is in Default stay where the workspace left them. ZoneSnap puts your other windows (the ones set to Put back) back where they were before it switched on: the same zone, or the same spot if a window wasn't in one, maximised or minimised as it was. Apps the workspace opened itself move to the Default zone covering their spot, so nothing is left in a gaming-sized gap. Apps the workspace itself set to Open, don't move, and games, are left where they are.

Auto gaming mode

With Auto gaming mode on (on the Gaming card, or ticked in the tray menu), gaming mode switches on by itself when a game you've added starts, and goes back to whatever you had before when the game closes. If you switch gaming mode off by hand mid-game, ZoneSnap leaves it off.

Games you add with Ctrl+Alt+A in the game zone are detected automatically. To detect a game without snapping it, use Add a game under Game layouts on the Apps page (Gaming).

Apps for your side panes

ZoneSnap keeps one list of your apps, shared by every workspace. For each workspace you choose where it puts each app: a zone, Open, don't move (opened if it isn't running, but left where it is), or Don't open (not part of that workspace). When a workspace switches on, it opens the apps it uses and snaps them into their zones; apps that are already open are just moved into place.

Adding an app

  1. Open the app and put it in the zone you want it in (or leave it outside the zones, for Open, don't move).
  2. Click the app and press Ctrl+Alt+A. It goes on the list for every workspace.

With a workspace on (Ctrl+Alt+G for gaming mode), the app is also placed in that workspace, in the zone it's in. With Default on, it gets that Default zone instead and isn't used by any workspace until you place it on the Apps page.

Moving apps between zones

Pick a workspace from the menu at the top of the Apps page. Where each app goes shows its zones on a picture of your monitor, with each app sitting in its zone, and two dashed strips underneath: Open, don't move and Don't open, which holds every other app on your list. Drag an app onto a zone or a strip to change where it goes. If the workspace is on, the app's window moves straight away.

Below the map, the list shows every app, with a menu for its zone in this workspace. Its buttons rename the app, edit the command that opens it, or remove it. Names and commands are shared, so a change shows in every workspace; Remove takes the app off the list everywhere (to take it out of just this workspace, choose Don't open). Clicking an app in the map takes you to its row. An app whose zone doesn't exist in this layout appears under the map, ready to drag into one.

Apps that shouldn't move

Set an app's zone to Open, don't move (or drag it into that dashed strip under the map) and the workspace leaves its window wherever it is. If it isn't running when the workspace switches on and it has a command, the workspace still opens it. Use this for something like Steam that you keep on one side of the screen all the time and don't want gaming mode to touch. An app you add with Ctrl+Alt+A while it isn't in a zone starts out as Open, don't move.

Games, launchers and apps in the game zone

An app you add in the Gaming layout's game zone counts as a game: auto gaming mode starts when it runs, gaming mode makes it borderless, and ZoneSnap never launches it. Game launchers and stores (Steam, the Epic Games Launcher, Battle.net, GOG Galaxy, the EA app, Ubisoft Connect, the Riot Client, the Xbox app and others) are the exception: they're open most of the time, so they're treated as ordinary apps even in the game zone.

Next to an app in the game zone, Not a game? or Treat as a game changes this. It's on the games in the Game layouts list too.

Renaming an app

ZoneSnap names apps after their program (OUTLOOK.EXE) or, for web apps, their website. Some web apps get a meaningless name, such as a Firefox web app showing as 5e79188c. Click an app's Rename button (the first of the buttons at the end of its row), type a name and press Enter. The name is the app's, so it shows in every workspace and in the Default view. Reset goes back to the automatic name. Games can be renamed the same way, here or under Game layouts, and the name shows in both places.

Where apps go on Default

The Apps page opens on Default. Pick it from the Workspace menu at the top of the Apps page to choose where your apps go when you're back on Default, after gaming mode or another workspace switches off. The map shows your Default zones with every app on your list; drag each one into the zone it should go to, or pick the zone from its menu in the list.

Default has two strips under the map too. Leave where it is keeps an app wherever the other workspace left it. Put back, where apps start, sends an app back to the zone or spot it was in before the other workspace switched on (see Going back to Default). Drag apps between the zones and strips, or use the menu on each row. Each row says which other workspaces use the app. An app you add with Ctrl+Alt+A while Default is on goes into the Default zone it's in, or Leave where it is if it isn't in one. If Default is on, a change moves the window straight away.

Discord, Spotify and other apps that won't shrink

The desktop versions of Discord and Spotify have a minimum window size that's too wide for a narrow side pane. Their web versions, opened as app windows in Microsoft Edge, don't have that limit and have no browser toolbar:

  1. Open https://discord.com/app (or https://open.spotify.com) in Edge and sign in.
  2. In Edge's menu choose Apps → Install this site as an app.
  3. Open the installed app (from the Start menu or its taskbar pin), put it in its zone and press Ctrl+Alt+A. ZoneSnap finds the app in Windows' app list and opens it the way the Start menu does (explorer.exe shell:AppsFolder\…), so there's nothing to type.

If ZoneSnap can't find the app, it asks for the command and shows the window's app ID. That usually means the window you added isn't the installed app: open the app from its taskbar pin or the Start menu and add it again.

Opens, but isn't snapped?A command with --app=https://… opens the website in a new Edge window, not the installed app, and Windows treats that as a different app, so ZoneSnap can't find it to snap it. The Apps page marks these rows: click Use the installed app to switch to the installed app. ZoneSnap also does this by itself when it starts, for any web app it can find in Windows' app list.
Two things to knowDiscord's web version only supports push-to-talk while its window is focused. Firefox's web apps don't work for side panes: their toolbar can't be hidden and they have a large minimum size.

Games

Windowed and borderless

Set your game to borderless or windowed in its own video settings, ideally at your game zone's size (2560 × 1080 on a 3840 × 1080 monitor) so it isn't stretched. Exclusive fullscreen can't be moved by anything outside the game.

Borderless in gaming mode

Some games only offer windowed mode with a title bar and frame. While gaming mode is on, ZoneSnap takes the title bar and frame off every game you've added and fits it to the game zone, like the Borderless Gaming app. If the game puts its frame back (after a resolution change, say), ZoneSnap takes it off again, and if the game resizes itself (some do once they've finished loading, as if they still had a frame), ZoneSnap gives the frame back for a moment, takes it off again and puts the game back. Snapping the game somewhere else, or dropping it somewhere with Alt-drag, moves the spot it's kept in. A game that keeps changing its own size is left alone after 5 tries in 10 seconds, until gaming mode starts again. When gaming mode switches off, the frame comes back. To keep frames on, turn off Make games borderless on the Gaming card of the Workspaces page.

Borderless outside gaming mode

To take the frame off a game (or any window) at other times, click it and press Ctrl+Alt+B; press it again to put the frame back.

Your games

Game layouts on the Apps page (pick Gaming from the Workspace menu) lists every game ZoneSnap watches for. Games you add with Ctrl+Alt+A in the game zone appear there; Add a game adds one without putting it in a zone (type its .exe name or pick a program that's running). Not a game? takes one off the list.

A layout for each game

Under Game layouts, each game has a Layout menu. Choose Its own layout and the game gets a copy of the Gaming layout to change, for example into a 4:3 layout for a retro game; Edit opens it on the Zones page. Whenever gaming mode starts while that game is running, ZoneSnap uses the game's layout instead of the Gaming layout, and your side apps go to the zones covering their usual spots. Choosing Gaming layout again deletes the game's own.

Games running as administratorIf a game runs as administrator, ZoneSnap can only move it when it's running as administrator too: tray menu → Restart as administrator.

Cursor lock

On a wide screen it's easy to fling the mouse off the game mid-fight. With cursor lock on, the mouse stays inside the game zone while you play, so it can't land on a side pane or bring up the taskbar.

StateWhere the mouse can goHow you get there
LockedOnly inside the game zoneClick on the game
FreeAnywhereLeave the game: Windows key, Alt+Tab, or Ctrl+Alt+F
OffAnywhereCtrl+Alt+L, or switch the workspace off
  • Leaving the game works as normal. Press the Windows key or Alt+Tab and the mouse is free to go anywhere. It stays free until you click back into the game.
  • Ctrl+Alt+F frees the mouse without opening Start and moves to the side pane you used last, for example to skip a song. Press it again to jump back into the game.
  • Pop-ups can't pull you out. If something takes over while you're playing (a Steam message window, a notification, or Windows switching to the taskbar), ZoneSnap puts the game straight back in front and keeps the mouse locked. The game's own windows, such as a quit prompt, are let through, and so is a window that keeps trying.
  • Moving a window with Alt-drag releases the lock while you drag.

Dimming side panes

Dimming darkens every zone except the game, so the side panes don't distract you. You can still see and click through them. Ctrl+Alt+D turns it on or off; set how dark on the General page.

A pane brightens while the mouse is over it or while you're using a window in it. To keep one bright, for example a guide you're following:

  • hover over it and click the pin button at its top centre (this doesn't take you out of the game),
  • point at it and press Ctrl+Alt+U, or
  • press Ctrl+Alt+Shift and its zone number, without touching the mouse.

Panes kept lit go back to normal when the workspace switches off.

The taskbar

  • Zones fit around it. When the taskbar is showing, zones shrink to fit beside it. When it's hidden, they use the whole screen, and your snapped windows follow.
  • Auto-hide while you play. A workspace can hide the taskbar while it's on and put your setting back afterwards. With cursor lock on, the mouse can't reach the screen edge, so the taskbar won't pop up.
  • Flashing apps don't bring it up. When an app wants attention, such as a new Steam or Discord message, Windows normally slides a hidden taskbar up. ZoneSnap stops that while a workspace is hiding the taskbar. The app's own notifications still work.
  • Taskbar on the side of the screen? ZoneSnap notices. A taskbar on the left or right sits beside a side pane rather than under your game, so ZoneSnap leaves it showing and the Auto-hide switch is greyed out. Your game zone keeps its exact size and place (a 2560-wide game stays 2560 wide); the pane between it and the taskbar gets narrower instead.
TipWindows' Do not disturb (Windows 11) or Focus assist (Windows 10) stops most pop-ups at the source while you play.

Multiple monitors

Zones can be on any monitor, and zone numbers run across all of them. With more than one monitor, the Zones page shows them in their Windows arrangement: click one to edit its zones, and the presets fit that monitor.

  • Move a monitor in Windows' display settings and its zones go with it.
  • Change a monitor's resolution and its zones scale to match.
  • Unplug a monitor and its zones move onto another one for now, then go back when it's plugged in again.

Changing a shortcut

  1. Open the Hotkeys page (tray menu → Hotkeys…).
  2. Click Change next to the shortcut.
  3. Press the new keys together, for example Ctrl+Shift+K. Press Esc to cancel, or Backspace to leave it without a shortcut.
  • For the zone shortcuts (send to zone, keep zone lit) you choose the modifier keys, such as Ctrl+Shift; the numbers 1 to 9 are added for you.
  • ZoneSnap won't let two things share a key, tells you what's already using it, and refuses keys Windows keeps for itself, such as Alt+Tab.
  • A letter or number needs Ctrl, Alt or Win with it, or you couldn't type it any more. Function keys can be used on their own.
  • Default next to a shortcut puts that one back; Reset shortcuts to defaults puts them all back.

Profiles

A profile is a complete, separate setup, so two people can share one Windows account without changing each other's zones, workspaces, apps or shortcuts. People with their own Windows accounts already have their own settings and don't need profiles.

  • New profile… (General page, or the tray menu's Profile submenu) asks for a name, then switches to it. A new profile starts as if ZoneSnap had just been installed: the first-run setup, and nothing carried over.
  • Switch to (or pick one in the tray's Profile submenu) switches off any workspace, puts your windows back, and restarts ZoneSnap on the other profile.
  • Rename and Delete are on each profile's row. You can't delete the profile in use.

Whose profile is on shows at the top of the sidebar, under the ZoneSnap logo, on every page; click it to switch to another profile, add one or manage them. The window's title bar says it too ("ZoneSnap – User"), so it shows on the taskbar and in Alt+Tab, and with more than one profile so does the tray icon's tooltip. That way nobody plays in someone else's setup by mistake. Auto gaming mode follows the profile that's on.

Backing up and sharing your settings

Under Back up and share on the General page:

  • Export everything… saves all of this profile's settings (layouts, workspaces, apps, shortcuts and options) to a file you choose. Keep it as a backup, copy it to another PC, or import it into another profile to give it a copy of yours.
  • Export layouts only… saves just your layouts (Default, Gaming, your workspaces' and your games'), for sharing with someone else. Your apps and shortcuts stay out of it.
  • Import… opens a file and shows what it holds before anything changes. Choose Import everything (ZoneSnap restarts with the imported settings) or Layouts only (keeps your apps, workspaces and shortcuts; a workspace's layout comes in only if you have that workspace). Either way, your current settings are saved first as ZoneSnap backup <date>.ini in your profile's folder.
Only import everything from a file you trustA full settings file can hold app commands, which ZoneSnap runs when a workspace switches on. The import lists them first. Layouts only never brings in apps, so it's safe for a layout someone has shared.

Zones are saved relative to their monitor, so a shared layout fits a monitor the same size, and is scaled onto a different one.

The tray menu

Right-click the ZoneSnap icon for quick access to gaming mode, your workspaces, your profiles, cursor lock, dimming, auto gaming mode and every page of the ZoneSnap window. Ticks show what's on. Double-click the icon to open the ZoneSnap window.

When a new version is out, Update now to ZoneSnap … sits at the top. Further down: User guide (this page), Check for updates, Start with Windows, Open settings file, Restart as administrator and Exit.

Troubleshooting

A window won't move or snap.
If it's a game, set it to windowed or borderless in its own settings; exclusive fullscreen can't be moved. If the app runs as administrator, choose Restart as administrator in the tray menu.
An app doesn't fill its zone.
It has its own minimum size. Use its web version as an Edge app (see Apps), or give it a bigger zone.
The mouse locks to the wrong pane.
Check the workspace's Game zone on the Workspaces page matches the zone your game is in.
The taskbar still pops up while I play.
Raise Keep the cursor off the taskbar edge on the General page. If an app's flashing brings it up, also turn off Settings → Personalization → Taskbar → Taskbar behaviours → Show flashing on taskbar apps in Windows.
Alt-click does something in my game.
Change the drag key to Win or Ctrl+Alt on the General page.
A shortcut doesn't work.
Another app may already use that key, or a game running as administrator may be swallowing it (restart ZoneSnap as administrator). Check what it's set to on the Hotkeys page, or try a different key.
Apps open in the wrong zones in gaming mode.
Gaming mode uses the Gaming layout, which can differ from Default. Check both on the Zones page, or move the app to the right zone on the Apps page.
Gaming mode turns on whenever Steam (or another app) is open.
That app is being treated as a game. Click Not a game? next to it on the Apps page (Gaming), or in the Game layouts list. If it should open with gaming mode, give it a command with its edit button, since games are never launched.
Windows don't go back when gaming mode switches off.
Only apps the workspace uses are put back, and only when you return to Default (not when you switch straight to another workspace). Apps set to Open, don't move in that workspace stay where they are, and an app with a Default zone goes to that zone instead. Check both on the Apps page.
The update check says it can't find any releases.
GitHub only answers for public repositories, so the update check can't see releases while ZoneSnap's repository is private.
My settings are gone after updating to 0.37.0.
0.37.0 moves the settings file from next to ZoneSnap into your Windows user folder, as a profile named after your Windows user name. If you started ZoneSnap under a different Windows account first, that account got the settings: the old file is still next to ZoneSnap as ZoneSnap.ini.old, so import it (General → Import…) after renaming it to end in .ini.
The ZoneSnap window won't open.
ZoneSnap shows a message saying why. Usually the WebView2 runtime is missing (install it from Microsoft) or, for the script version, ui.html, the src folder or the Lib folder isn't next to the script. Zones, gaming mode and your shortcuts keep working from the tray icon meanwhile.

Still stuck? Please report it on the project's GitHub Issues page, with what you did and what happened.

Uninstalling

  1. On the General page, turn off Start with Windows.
  2. Right-click the tray icon and choose Exit.
  3. Delete the ZoneSnap folder (including any ZoneSnap backup files in it, unless you want to keep them), and %LOCALAPPDATA%\ZoneSnap (paste it into File Explorer's address bar), where ZoneSnap keeps the ZoneSnap window's files.

If ZoneSnap was hiding the taskbar when you exited, it puts your own setting back first.
